People Counter – JavaScript Mini Project
Project Description: 
People Counter is a simple front-end web application built using HTML, CSS, and JavaScript.
The application simulates counting the number of people entering a subway station. Users can increment the count and save previous entries, demonstrating core concepts of DOM manipulation and event-driven programming.
This project was built as my first JavaScript mini project to strengthen my fundamentals in frontend development.

The Technologies Used are: 
HTML – Structure of the webpage
CSS – Styling and layout
JavaScript – Application logic and interactivity

Features:
1.Increment people count using a button
2.Save the current count and display previous entries
3.Reset the counter after saving
4.Dynamic UI updates using JavaScript

 Concepts Learned:
1.DOM manipulation using document.getElementById
2.Handling user events with onclick
3.State management using JavaScript variables
4.Updating UI dynamically using textContent
5.Function creation and reuse
6.String concatenation and data formatting
7.Separation of concerns (HTML, CSS, JS)
